# scoop-swamp

[Scoop](https://scoop.sh) bucket for [swamp](https://github.com/swamp-club/swamp).

```powershell
scoop bucket add swamp https://github.com/webframp/scoop-swamp
scoop install swamp/swamp
```

Updates are detected every six hours by the Excavator workflow.
Swamp is licensed under AGPL-3.0-only; this bucket's manifests are unofficial.
